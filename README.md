# Fatigue Detector

Fatigue Detector - desktop-приложение для мониторинга усталости пользователя по видеопотоку с веб-камеры. Проект объединяет детекцию ключевых точек лица и позы через MediaPipe, расчет поведенческих метрик, мониторинг активности клавиатуры и мыши, сохранение сессий и адаптивную модель классификации в интерфейсе PySide6.

Проект подходит для исследовательских прототипов и задач наблюдения за состоянием оператора, где важно в реальном времени отслеживать признаки усталости и сохранять данные для последующего анализа.

## Возможности

- Обработка видеопотока с веб-камеры в реальном времени.
- Детекция лица и позы на основе MediaPipe task-моделей.
- Расчет метрик усталости: моргания, зевки, PERCLOS, наклон головы, трение глаз, активность клавиатуры/мыши и время простоя.
- Desktop-интерфейс с видеопотоком, текущим состоянием усталости, уверенностью модели, счетчиками метрик, рекомендациями и логами сессии.
- Debug-режим с наложением актуальных метрик прямо на видеокадр.
- Отображение landmarks для проверки работы детекторов.
- Сохранение сессий в CSV и SQLite через модуль сбора метрик.
- Online-адаптация классификатора: приложение может дообучать легкий слой на данных текущих сессий и смешивать его прогноз с основной моделью.
- Скрипт сборки Windows-приложения через PyInstaller.

## Структура проекта

```text
fatigue-detector/
- build_app.py              # Сборка GUI-приложения через PyInstaller
- requirements.txt          # Python-зависимости
- models/                   # MediaPipe task-файлы и состояние online-модели
- docs/                     # Документация и проектные заметки
- images/                   # Пример изображения для экспериментов
- src/
  - app.py                  # Основное PySide6 desktop-приложение
  - main.py                 # Экспериментальный запуск видео-пайплайна
  - main_image.py           # Экспериментальная обработка изображения
  - pipeline.py             # Оркестрация метрик усталости
  - config.py               # Пути к моделям и runtime-конфигурация
  - metrics_config.yaml     # Настройки порогов метрик
  - collector/              # Сбор, анализ и визуализация метрик
  - detectors/              # Детекторы лица, позы и ключевых точек
  - metrics/                # Реализации отдельных метрик усталости
  - model/                  # Классификатор, признаки, обучение и online-слой
  - tools/                  # Вспомогательные инструменты
  - utils/                  # Мониторинг ввода, рекомендации и трекинг состояния
```

Сгенерированные данные (`src/output/`), сборки (`build/`, `dist/`), виртуальные окружения, SQLite-базы, отчеты и временные датасеты не должны попадать в git.

## Требования

- Python 3.11
- Веб-камера, доступная через OpenCV
- Windows рекомендуется для текущего desktop-сценария
- Зависимости из `requirements.txt`

В папке `models/` должны лежать MediaPipe task-файлы:

- `face_landmarker.task`
- `pose_landmarker_lite.task`
- опционально `pose_landmarker_full.task` и `pose_landmarker_heavy.task` для экспериментов

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск приложения

Запускайте приложение из корня репозитория:

```powershell
python src\app.py
```

В интерфейсе отображаются:

- live-видео с камеры;
- текущий уровень усталости и уверенность модели;
- события моргания и зевка;
- PERCLOS, наклон головы, трение глаз;
- активность клавиатуры и мыши;
- путь сохранения текущей сессии;
- логи обработки под видеопотоком.

Горячие клавиши:

- `S` - старт или остановка обработки
- `R` - сброс состояния текущей сессии
- `D` - включить или выключить debug-overlay
- `L` - включить или выключить landmarks
- `Q` - закрыть приложение

## Экспериментальные запуски

Видео-пайплайн без основного GUI:

```powershell
python src\main.py
```

Обработка изображения:

```powershell
python src\main_image.py
```

## Обучение и модели

Модуль `src/model/` содержит извлечение признаков, генерацию синтетических данных, обучение классификатора и online-адаптацию. Базовый запуск обучения:

```powershell
python src\train_model.py
```

Сгенерированные датасеты, отчеты, SQLite-файлы и runtime-сессии не следует коммитить. В репозитории стоит хранить только те модели и task-файлы, которые нужны для запуска приложения или воспроизводимых экспериментов.

## Сборка executable

После установки зависимостей запустите:

```powershell
python build_app.py
```

PyInstaller создаст сборочные артефакты в `build/` и `dist/`. Эти папки игнорируются, потому что их можно пересобрать из исходников.

## Рекомендации для разработки

- Выполняйте команды из корня репозитория, чтобы относительные пути к моделям и output-директориям работали корректно.
- Храните MediaPipe task-файлы в `models/`.
- Не коммитьте виртуальные окружения, `__pycache__`, runtime-сессии, SQLite-базы, build-артефакты и временные отчеты.
- При изменении логики усталости проверяйте связку `src/metrics/`, `src/pipeline.py` и отображение данных в `src/app.py`.
